My Cloud Login

My Cloud is your private, encrypted home for files and secrets. Upload documents to storage that only you control, then split any sensitive secret — a password, a recovery key, a message — into several shares that you can hand out to people you trust. No single share reveals anything on its own: only when enough of them are brought back together can the secret be reconstructed.

How does it work?

From a single secret to shares you can trust — and back again. See the maths →

1. Generate a scheme

My Cloud creates a scheme of n shares with a threshold k — the number of shares needed to unlock a file.

2. Share the shares

Hand out the n shares to trustworthy partners — one each, so no one person holds the whole key.

3. Encrypt files

Any file — a document, an image, anything — is encrypted using k of the n shares.

4. Decrypt together

Only k partners with the right shares can decrypt. With just k−1, an attacker learns absolutely nothing.
